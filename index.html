About the app

Study Task Manager is a small web application built for university students who need to keep several subjects moving at the same time. Each task stores a title, the course it belongs to, a due date, a description and personal notes.

The application runs entirely in the browser. Tasks are saved in the browser's local storage, so they are still there after the page is reloaded, and no account or server is required.

  • Sign in before your task list is shown.
  • Create, edit and delete tasks, with a confirmation step before deleting.
  • Validation that blocks empty required fields and impossible due dates.
  • Every page shows the current date and time in the footer.
